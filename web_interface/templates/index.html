Pools

Group clips into pools. Timetables that switch pools through the night are under Triggers.

Greeting Pools

A pool plays its greetings in random order (using every greeting once before any repeats) or, with Play order set to In order, top to bottom and then loops. Each greeting keeps its own mouth-sync timestamps, so generate timestamps for every file in a pool.

Triggers

What starts the prop and what it plays: sensors, network requests, and the clock.

Sensor Ports
Sensors with no pool play the default audio. A schedule (listed under the pools) plays whichever pool is current. Network triggers choose their pool in the table below.

Timed Triggers

Plays a clip, pool or schedule once at a set time on a party night, such as the costume contest announcement. If the prop is busy at that moment it waits for up to 5 minutes, then skips it for the night. It only fires when the clock is set (see Dashboard).

The night at a glance
Announcements and pool-schedule steps in time order. Times before 06:00 count as after midnight.
Pool Schedules

A pool schedule changes which pool a sensor port or network trigger plays as the night goes on. It does not start anything by itself: a visitor or request still has to trigger it. To play something at a set time with nobody triggering it, use a timed trigger above. Make each later pool include the earlier clues so late players still hear them. Times before the night rollover count as after midnight of the same party night.
